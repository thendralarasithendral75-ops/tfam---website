# TFAM Insurance Surveyors & Loss Assessors — Website

A Next.js 14 (App Router) project.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint

## Project structure

```
app/                 App Router entry (layout.jsx, page.jsx)
components/           TFAMWebsite.jsx — the full site component
styles/               globals.css (Tailwind)
public/assets/images/ Logo, favicons, and director photos
```
